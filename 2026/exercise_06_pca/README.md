# Exercise 6: PCA for airfoils

Open `exercise_6_pca.ipynb` and run the cells in order. Complete the lines marked `TODO`, including array selections inside the plotting cells. Loading and figure formatting are supplied; students complete the PCA calculations, grid restoration and the choice of data to plot. `exercise_6_pca_solution.ipynb` contains the completed exercise.

Keep this whole folder together. If downloaded as a ZIP from Moodle, extract it first. Open `exercise_06_pca` as your working folder in VS Code, or start Jupyter from that folder, then open the notebook. Both notebooks load `data/velocities_small.npz` relative to the working folder.

Use the course Python environment as the notebook kernel. It needs NumPy, Matplotlib, SciPy and scikit-learn, plus Jupyter or VS Code notebook support. No additional packages or downloads are needed for the perturbation experiment.

## Included data

- `data/velocities_small.npz` contains 200 speed snapshots of shape `(207, 500)` and a Boolean airfoil mask. It is a real compressed NumPy archive (about 36 MB), not a Git LFS pointer. NumPy reads it directly; do not unzip it.
- This is a lossless repackaging of the small dataset already distributed with the 2025 exercise. Both arrays and their dtypes are unchanged. The source NPZ SHA-256 was `7a49eec5a8de8cae9de71aa1902e73b217a6215be1d0c085aa62197d39e1b715`.
- The 669 MB full dataset is not required. No network access or Git LFS is needed to load this exercise's data.
- The archive has no timestamps; the notebook uses snapshot indices and does not assume a physical sampling interval.
- `velocity_animation.gif` is a 10-second preview of the first 100 frames of the original animation, at its original playback speed. It illustrates the source flow; it is not a frame-by-frame rendering of the small dataset.

## Instructor notes

Sections 1–5 are the core exercise. Sections 1–4 use the original data: students build PCA from NumPy SVD, compute component variances, project and reconstruct snapshots, measure reconstruction errors against the unexplained variance, then compare against scikit-learn; Section 5 adds a synthetic distributed disturbance to a separate copy, then uses PC coordinates and component subtraction to identify and remove it. The original arrays and PCA model remain available for extensions A–C. Extension D explores weaker disturbances.

The notebooks use observations in rows, spatial modes `v_i`, and the notes' SVD interpretation. Centering without per-pixel standardization is an explicit choice. The 90% component count is computed from the current data, not hard-coded. Reconstructed images share color limits; signed modes use a diverging color scale. Calculations and plots are in separate cells wherever practical.

The 2025 notebooks remain under `../../2025/exercise_06_pca/` for comparison. Additional local snapshots made before this revision are in `TA_for_ML/output/pca_review/legacy_2025_20261013/`. This new exercise does not change those notebook sources.

The local `.gitattributes` makes a narrow exception to the repository's general Git LFS rule, so the included teaching dataset is stored as an ordinary file.
